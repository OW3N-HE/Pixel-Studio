PIXEL STUDIO
0.2.1 · Windows x64

Getting started

Choose an edition. Press play.

One installer. Three ways to use Pixel Studio. Start with Desktop unless you need another edition.

RECOMMENDED

Desktop

Standalone app with tray playback, Windows startup and remembered USB settings.

CHROME / EDGE

Web

Open the Pixel Studio Web shortcut. It starts the local service and your browser together.

OPENRGB USERS

OpenRGB plugin

Use the Pixel Studio tab in a compatible OpenRGB installation. OpenRGB is not bundled.

01 / Install and connect

  1. Run the installer. Choose all users or only your account. Desktop is selected by default; Web and OpenRGB are optional. Required runtimes are included.
  2. Open your edition. Connect a controller with compatible USB/Adalight firmware. In Settings, select USB and its port, then set the matrix size and pixel order.
  3. Choose an animation and press Play. For network output, select DDP and enter your WLED controller's IP address. Use only one sender per device.

Web ZIP: extract everything and run Start-Pixel-Studio.cmd. Directly opening index.html supports preview and browser USB, but does not start the temperature or DDP service.

02 / Update

Desktop

Settings → Check for updates → Download selected package → Install downloaded update. The installer is verified before you confirm installation.

Web / OpenRGB

Check for updates, download the Windows installer, then run it manually. Quit Desktop and OpenRGB from their tray menus first.

Keep the existing installation scope, folder and component choices. In-place updates retain personal settings; firmware is not flashed. If files are in use, close the named Pixel Studio processes and retry. Never skip locked files or stop unrelated Node.js processes.

Web / Desktop controls

  1. Preview and output are separate. Selecting a card updates the local preview. Press the blue Play button to send to the controller; a red Stop button means output is active. Read the status message for connection errors. One outlined card marks the current selection.
  2. Find animations or media. Use the category, search, favorites and shuffle controls. Media switches content sources. Web lets you choose a local image or video and its fit mode. Desktop provides a folder-based media library.
  3. Adjust the selected design. Brightness affects output; available speed, style and color controls depend on the card. Custom colors for animations and clocks update the preview as you edit. Temperature colors are saved with Apply; Cancel leaves them unchanged.
  4. Choose your appearance. Settings contains language, theme, output, matrix size and updates. Desktop window, taskbar and tray icons follow the application theme; Follow system uses Windows light/dark appearance. Installer and Sensor executable icons use the default blue logo. Existing pinned shortcuts may retain their saved icon.

These interface instructions apply to Web and Desktop. The OpenRGB plugin keeps its existing interface and features; this redesign does not add the new themes or media UI to OpenRGB.

Temperature cards

The Information category contains four separate CPU/GPU temperature designs alongside the clock. Select the card you want, choose CPU/GPU colors, and adjust the sampling interval where available. A missing or unreadable sensor is shown as unavailable, not as a zero-degree measurement.

Desktop uses its own sampler. Web uses the local launcher service, so open it through the installed shortcut or Start-Pixel-Studio.cmd, not just index.html. If monitoring is unavailable, read the status message before retrying.

Temperature monitoring and driver setup require explicit installer consent. A compatible existing PawnIO driver is reused. Do not uninstall a shared driver, stop Fan Control, or change fan settings to troubleshoot Pixel Studio. Ordinary animation playback does not require sensor readings.

Useful to know

Background playback: Desktop settings control Windows startup, hiding on login, closing to tray and resuming playback over USB or DDP, with saved shuffle and output settings. The Desktop media library remembers its folder and selection; restoration requires the file to remain available. Browser-selected media must be chosen again after reopening the Web page. The last Web page closing stops its output; the launcher service exits after a short grace period when no other clients are active.

OpenRGB compatibility: Windows x64, Plugin API 4, Qt 5.15.0. If its library path is outdated, select <install folder>\app and <install folder>\runtime\node.exe.

Settings, uninstall and connection help

Desktop: %APPDATA%\Pixel Studio Desktop
OpenRGB: %APPDATA%\Pixel Studio for OpenRGB
Web preferences are stored in the browser profile. These are data folders, not extra installations.

Uninstall through Windows Settings. Choose "Uninstall and keep settings" (default), or "Uninstall and completely clear data" to also delete this account's settings, caches, remembered ports and upgrade backups. Both options remove the plugin installed by Setup; quit Desktop and OpenRGB from the tray first, and restart Windows if requested. Other plugins, shared PawnIO, projects and external media are kept. Browser preferences must be cleared in the browser separately.

USB missing or busy? Check your data cable and quit other senders. After changing controllers, clear the saved USB device and select the new port. A working preview does not mean output has started.

Unsigned Windows build. Windows may show a security prompt. Download only from the official repository. Actual device playback and the full installed upgrade flow still need real-world feedback.

0.2.1 · Windows x64

开始使用

选一种方式，让像素动起来。

一个安装包，三种使用方式。不确定选哪个，就选桌面版。

推荐使用

桌面版

独立运行，支持托盘播放、随 Windows 启动，以及记住 USB 设备和设置。

CHROME / EDGE

网页版

打开 Pixel Studio Web 快捷方式，自动启动本地服务并打开浏览器。

OPENRGB 用户

OpenRGB 插件

在兼容的 OpenRGB 中打开 Pixel Studio 标签页。安装包不包含 OpenRGB 主程序。

01 / 安装并连接

  1. 运行安装包。选择所有用户或仅当前用户安装。默认勾选桌面版，网页版与 OpenRGB 按需选择，所需运行环境已包含。
  2. 打开使用的版本。连接兼容 USB/Adalight 固件的控制器，在设置里选择 USB 和对应串口，再设置屏幕尺寸及像素排列。
  3. 选择动画，点击播放。网络输出请选择 DDP 并填写 WLED 控制器 IP。同一个设备不要同时使用多个发送程序。

网页版 ZIP：完整解压后运行 Start-Pixel-Studio.cmd。直接打开 index.html 可预览和使用浏览器 USB，但不会启动温度或 DDP 服务。

02 / 更新

桌面版

设置 → 检查更新 → 下载所选版本 → 安装已下载的更新。程序会先校验安装包，再由你确认安装。

网页版 / OpenRGB

检查更新，下载 Windows 安装包后手动运行。安装前请从托盘菜单完全退出桌面版和 OpenRGB。

沿用原安装范围、目录和组件选择，原位更新保留个人设置，不刷写固件。文件被占用时，退出提示中的 Pixel Studio 相关进程后重试；不要跳过文件，也不要结束其他软件的 Node.js 进程。

网页版 / 桌面版界面操作

  1. 预览与输出是两回事。选中卡片会更新本地预览，点击蓝色播放按钮才向控制器发送；红色停止按钮表示正在输出。连接异常请查看状态提示。卡片外侧的一圈描边表示当前选中项。
  2. 查找动画与媒体。使用分类、搜索、收藏和随机播放。媒体按钮用于切换内容来源：网页版选择本地图片或视频并设置画面适配，桌面版使用文件夹媒体库。
  3. 调整当前设计。亮度影响输出；速度、样式和配色控件随卡片变化。普通动画和时钟的自定义颜色会随编辑更新预览；温度配色点击“应用”才保存，“取消”不会覆盖原设置。
  4. 选择界面外观。设置里包含语言、主题、输出、屏幕尺寸和更新。桌面窗口、任务栏与托盘图标跟随应用主题，“跟随系统”使用 Windows 的浅色 / 深色外观。安装器和 Sensor 程序使用默认蓝色 Logo；已经固定的快捷方式可能保留原图标。

以上界面说明仅适用于网页版和桌面版。OpenRGB 插件保留原有界面和功能，不引入本次新主题与媒体界面。

温度卡片

“信息”分类中包含四张独立 CPU / GPU 温度卡片，与时钟并列。选择喜欢的卡片，设置 CPU / GPU 配色，并按需调整采样间隔。缺失或无法读取的传感器显示不可用，不把无数据当作零度。

桌面版使用自己的采样器；网页版通过本地启动器服务读取，因此请使用已安装的快捷方式或 Start-Pixel-Studio.cmd，不要仅打开 index.html。采集不可用时，先查看状态提示再重试。

温度采集及驱动安装需要在安装器中明确授权。兼容的现有 PawnIO 驱动会被复用。请勿卸载共用驱动、停止 Fan Control 或修改风扇设置来排查 Pixel Studio；普通动画播放不依赖温度读数。

你可能还需要知道

后台播放：桌面设置可控制随系统启动、登录时隐藏、关闭到托盘和继续上次 USB 或 DDP 播放，保留随机播放和输出设置。桌面媒体库会记住文件夹和选中项，恢复时原文件必须仍可读取。网页版重新打开后需要重新选择本地媒体。关闭最后一个网页后会停止该页输出，启动器服务在没有其他客户端使用时延迟退出。

OpenRGB 兼容性：Windows x64、Plugin API 4、Qt 5.15.0。旧动画库路径不正确时，选择 <安装目录>\app 和 <安装目录>\runtime\node.exe。

个人设置、卸载与连接问题

桌面版：%APPDATA%\Pixel Studio Desktop
OpenRGB：%APPDATA%\Pixel Studio for OpenRGB
网页版设置保存在浏览器用户数据中。这些是数据目录，不是重复安装。

通过 Windows 设置卸载，可选择“卸载并保留设置”（默认）或“卸载并完全清除”。完全清除还会删除当前卸载账户的设置、缓存、记住的串口和升级备份。两种方式都会移除安装器安装的插件；请先从托盘退出桌面版和 OpenRGB，若提示重启，请重启完成删除。其他插件、共用 PawnIO、开发项目和外部媒体不会删除；浏览器内的设置需在浏览器中另行清除。

串口找不到或被占用？检查数据线并退出其他发送程序。更换控制器后，清除记住的 USB 设备再选择新串口。预览在动不代表已开始发送。

Windows 安装包未签名，系统可能显示安全提示，请仅从官方仓库下载。实际灯屏播放和完整安装升级仍需实机反馈。
